# BankATM

A beginner-friendly Python ATM simulator built for learning. Users can register a name and PIN, log in, check their balance, deposit money, withdraw funds, and log out.

## Run it

```bash
python app.py
```

## Project files

- `app.py` — main ATM menu and login flow
- `banking_pkg/account.py` — balance, deposit, withdrawal, and logout logic
